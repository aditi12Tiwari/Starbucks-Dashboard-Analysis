# Starbucks-Dashboard-Analysis

📌 Overview

This project is an interactive data analytics dashboard built to analyze Starbucks beverage data and uncover insights related to calories, sugar, caffeine, and global distribution.

The goal was to transform raw data into a story-driven dashboard that helps stakeholders make better decisions about product offerings and customer preferences.

📊 Business Insights
🍫 White Chocolate Mocha is among the highest calorie beverages
☕ Classic Espresso Drinks contain the highest caffeine levels
🥤 Frappuccino variants contribute heavily to sugar intake
🌍 Majority of beverage distribution is concentrated in the US market
